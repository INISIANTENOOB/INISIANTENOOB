## 🇺🇸 About me

I'm a **Java developer with 2 years of experience**, focused on **Minecraft server software and plugin development** on **Paper** and **Folia**.
I like the hard parts: concurrency, profiling, and making a server keep a stable TPS when a lot of players pile into the same place.

- 🔧 **Plugin development** with the Paper API: commands, events, configs, schedulers, and Folia-safe code
- ⚡ **Performance work**: profiling hot paths, reducing main-thread load, and spreading work across cores
- 🗄️ **Data layer**: PostgreSQL for persistent plugin and server data
- 🧪 **Quality**: regression tests and reproducible Gradle builds

## 🚀 Featured project · Projeto em destaque

### ⭐ EndstarMC &nbsp; <img src="https://img.shields.io/badge/repo-private-555?style=flat-square&logo=github"/> <img src="https://img.shields.io/badge/Java-21-ED8B00?style=flat-square&logo=openjdk&logoColor=white"/> <img src="https://img.shields.io/badge/Minecraft-1.21.11-62B47A?style=flat-square"/>

**🇺🇸** A performance-focused Minecraft server fork built on **Folia's regional threading** and **Paper's** improvements.

- **Multi-core entity tracker:** in crowded regions, visibility checks are split across several CPU cores instead of running on a single thread
- **Gameplay optimizations:** SavedData, redstone, items, collisions, hoppers, and optional DAB (dynamic activation of brain)
- **Lag monitor:** detects slow or stalled regions and sends a report to Discord (world, chunks, players, entities, block entities), also saved as `.yml`/`.txt`
- **250-player tuning profile:** load target currently being validated
- **Engineering:** patch-based build on Gradle + paperweight, a regression test suite, and the existing world format kept intact

**🇧🇷** Fork de servidor Minecraft focado em performance, construído sobre o **threading regional do Folia** e as melhorias do **Paper**: tracker de entidades em vários núcleos, otimizações de redstone, hoppers e colisão, monitor de lag com relatórios no Discord, perfil de ajuste para 250 jogadores (meta em homologação) e suíte de testes de regressão.
